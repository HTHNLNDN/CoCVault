## Conventions
| Mark | Meaning |
|---|---|
| `[?]` after a word | Uncertain reading of the handwriting |
| `~~text~~` | Struck through in the original |
| `[struck]` / `[blacked out]` | Crossed out and unreadable |
| *(italic in parentheses)* | Description of a drawing or layout, not the author's words |
| `[sic]` | Written that way in the original |
| ⟦ ⟧ | The handouts' own out-of-character notes (printed in double square brackets, changed so Obsidian doesn't make them links) |

Spelling and grammar are kept as written (e.g. "Texaxe", "Insmuth", "The Chace"). The only additions are wiki-links. Each journal entry ends with the full page scan so you can check any reading.

## Sources
- **Ponzi PDF** — *Mystery of the Ponzi Potion* (23 scans): Notebook I spreads 1–19, Ponzi's character sheet, and Notebook II pages 1–7. Scans: `scan-A01` … `scan-A23`.
- **Notebook II PDF** (6 scans): Notebook II pages 8–19, including the Bible handout. Scans: `scan-B01` … `scan-B06`.

## Sketches
Every drawing, map and handout has been cropped out of the scans and cleaned up (paper whitened, ink darkened) into `Attachments/Sketches`. File names start with the scan they came from (`a05-…` = scan A05).
