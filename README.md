# CoCVault

Obsidian vault for our Call of Cthulhu campaign.

Open this folder as a vault in Obsidian and start at `Ponzi Campaign Notes/00 Campaign Home.md`.

- **Open Threads and Clues** — live lists of open, in-progress, resolved and dead-end threads (powered by `Case Board.base`).
- **How to Read the Graph** — the graph colour legend and how to update a thread's status. The colour settings are in `.obsidian/graph.json`.
